# Cella Nespresso — simulazione 3D nel browser

Three.js + Rapier (fisica reale delle capsule). Unità: 1 unità = 1 dm.

    npm install
    npm run dev        # http://localhost:5173

Fisica reale: capsule nei cassoni inclinati, imbocco della vite, nastri, hopper e vasca.
Animata/cinematica: vite (singolatore a passo), scrambler (orientamento), guide, delta, scatole, AGV.

Controlli: 1-6 viste · WASD/QE muovi · L etichette · H nascondi HUD · click su cassone = info.
URL utili: `?speed=4` `?hud=0` `?cam=x,y,z,tx,ty,tz` `?norender` (solo logica, per test).
